# Jenny Mod — порт на Fabric для Minecraft 26.3

[English](README.md) · **Русский**

> **Только 18+.** Это порт мода для Minecraft с порнографическим контентом. Не используйте, не собирайте и не распространяйте его, если вам нет 18 лет.

Неофициальный порт **Jenny Mod (Fapcraft) 1.1.0** от Schnurri (trolmastercard) с Minecraft 1.12.2 / Forge на **Minecraft 26.3 / Fabric**. У оригинального мода нет версии для актуального Minecraft. Этот проект переносит его персонажей и сцены, и любой может его продолжить.

В репозитории **только собственный код и файлы порта**. Модели, анимации, текстуры и звуки оригинала принадлежат его автору и сюда **не входят**. Gradle-задача извлекает их из вашей копии оригинального jar и конвертирует под новый движок (см. [Сборка](#сборка)).

## Состояние

Играбельно, но не всё перенесено.

**Работает**

- 9 персонажей с яйцами призыва: Jenny, Ellie, Bia, Bee, Allie, Luna, Slime, Galath, Manglelie.
- Оригинальные Bedrock-модели и анимации через GeckoLib 5; одетые и раздетые модели у Jenny, Ellie, Bia и Slime.
- Меню по правому клику с оригинальными ценами (Jenny: изумруды, жемчуг Края, алмазы; Luna: рыба).
- Сцены как цепочки оригинальных клипов: `G` — следующая стадия, `Shift` — закончить.
- Игрок участвует через встроенную в модель персонажа модель игрока, нарисованную **вашим скином** (тонкие и широкие руки).
- Камера от первого лица из глаз этой модели (`F5` — вид сбоку).
- 193 оригинальные звуковые реплики, привязанные к ключевым кадрам.
- Предупреждение 18+ при первом запуске; русский и английский перевод.

**Пока не перенесено**

Естественный спавн в биомах, ИИ и бой персонажей, диалоги, инвентарь девушек, структуры, лампа Allie, монета и полёт Galath, запросы в мультиплеере, броня на персонажах.

**Убрано намеренно**

- **Goblin и Kobold** — их модели детского роста (хитбокс 0.99 блока). Исключены из импорта и кода.
- **Клипы принуждения у Galath** (`rape_*`) и их звуки.

Пожалуйста, сохраняйте это в публикуемых форках.

## Требования

- Minecraft **26.3**, Java **25**
- [Fabric Loader](https://fabricmc.net/use/) 0.20.1+
- [Fabric API](https://modrinth.com/mod/fabric-api) 0.165.0+26.3
- [GeckoLib](https://modrinth.com/mod/geckolib) 5.5.7 для Fabric 26.3
- Оригинальный jar **Jenny Mod 1.1.0 для 1.12.2** (для сборки)

Для мультиплеера мод нужен и на сервере, и у каждого игрока.

## Сборка

1. Установите JDK 25 (например, [Temurin](https://adoptium.net/)).
2. Скачайте оригинальный **Jenny Mod 1.1.0 (Minecraft 1.12.2)** с официальной страницы автора.
3. Импортируйте его ассеты (один раз или после обновления конвертера):

   ```bash
   ./gradlew importOriginalAssets -PoriginalJar=путь/к/jenny-mod-1.1.0.jar
   ```

   На Windows — `gradlew.bat`. Можно указать и уже распакованную папку.
4. Соберите:

   ```bash
   ./gradlew build
   ```

   Готовый мод: `build/libs/jenny-mod-1.1.0+26.3.jar`. Положите его в `mods` вместе с Fabric API и GeckoLib.

Запустить тестовый клиент: `./gradlew runClient`.

### Что меняет импорт

Оригинальные файлы сделаны под GeckoLib 3 на 1.12.2. Импорт (`gradle/original-assets.gradle`) конвертирует их:

- Переносит модели и анимации в папки GeckoLib 5: `geckolib/models` и `geckolib/animations`.
- Чинит следы экспортёра, на которых GeckoLib 5 падает: имена изингов внутри значений (`"-97.03+easeInOutSine"`), одиночные `easeInOutBack` / `yaw` / `pitch`, `"50+."`, `NaN`.
- Сортирует ключевые кадры по времени и **держит значение первого кадра канала с нулевой секунды**. Без этого GeckoLib 5 раздувает кости мимики до огромных значений (гигантский рот, улетающие глаза).
- Добавляет кость камеры от первого лица `boyCam` в модели, где её нет.
- Отбрасывает Goblin, Kobold и клипы `rape_*`; копирует только используемые звуки и текстуры.

## Управление

| Клавиша | Действие |
| --- | --- |
| Правый клик по персонажу | Меню действий |
| `G` (настраивается) | Следующая стадия сцены |
| `Shift` | Закончить сцену |
| `F5` | Первое лицо / вид сбоку |

## Структура

```
src/main/java/.../sexmod/      общий код: сущность, действия, логика сцен, сеть
src/client/java/.../client/    рендер, слой скина партнёра, камера сцены, меню, звуки
src/main/resources/            собственные файлы порта: переводы, яйца, метаданные
gradle/original-assets.gradle  импорт и конвертация оригинальных ассетов
original-assets/               импортированные ассеты (в .gitignore, создаются импортом)
```

Главные точки входа: `GirlEntity` (машина состояний сцены), `GirlActions` (меню и цены), `GirlRenderer` / `PartnerSkinLayer` (рендер и модель игрока), `SceneCamera` (камера от первого лица), `CueSounds` (звуки).

### Автопроверка сцены

Для разработки есть тест, включаемый флагом: он ставит персонажа рядом с вами в копии мира, запускает действие и делает скриншоты.

```bash
./gradlew runClient -Pautotest=jenny:blowjob -Pworld=<папка мира в run/saves> -Pshots=8
```

Дополнительно: `-Pcamera=THIRD_PERSON_BACK`. Без `-Pautotest` этот код не выполняется.
